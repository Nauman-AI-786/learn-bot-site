Privacy Policy

Last updated: October 23, 2026

learn-bot ("the app") is a personal automation tool that uploads videos to the owner's own YouTube channel using the YouTube Data API.

Information we access

The app connects to the owner's Google account through Google OAuth and uses only the permission needed to upload videos to the owner's YouTube channel.

How information is used

Access is used only to upload and manage the owner's own videos. The app does not read, collect, or analyze any other personal data.

Data storage and sharing

The app does not store personal user data on any server and does not sell, share, or disclose any information to third parties. OAuth credentials are kept private as secure secrets in the owner's own GitHub repository settings.

Google API Services

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data deletion

Access can be revoked at any time from https://myaccount.google.com/permissions.
